# KING CODER

**Personal AI Engineer — Starter UI**

KING CODER is a mobile-first Bengali-friendly interface prototype for a personal AI coding assistant.

## Run
Open `index.html` in any modern browser.

## Current status
This commit contains only the frontend prototype. No AI provider/API, server, database, code execution sandbox, GitHub write automation, or deployment agent is connected yet. The chat currently displays a demo response.

## Planned milestones
1. Connect a secure backend and an AI model.
2. Add project planning, file editing, and code generation tools.
3. Add safe test/build workflows and GitHub integration.
4. Add deployment integrations with explicit approval for major actions.

## Cost and safety
Free service tiers have quotas and usage limits. API keys must be stored on a server as secrets and must never be placed in browser JavaScript.
